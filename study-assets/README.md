# Lecture reference figures

These figures were extracted from the user's 23 uploaded lecture presentations.
The source decks credit Ahmed Katsha, Raritan Valley Community College, and
OpenStax / Rice University (CC BY 4.0), with exceptions credited in individual
slides and figures. Original embedded credits are preserved. Full original slide
text, source filenames, slide numbers, alt text, original media hashes, resizing
information, and packaged image hashes are recorded in `study-data/images.json`.
Consult the individual source attribution for third-party figures.

Pictures are resized/re-encoded for Discord delivery without removing labels.
The original presentations are not included. This collection is not a claim of
ownership or a separate license for third-party illustrations.

Matching is automatic using the question's correct answer, explanation, cited
slides, figure alt text, and labels. Related figures can show broader context;
this is not an independently reviewed set of image-identification questions.
Figures appear after answering. Optional private previews warn about labels.
Related questions share illustrations; images are not unique to each question.

Rebuild with `python scripts/extractStudyImages.py /path/to/uploads`, then
`python scripts/buildStudyImageIndex.py`. Optional local OCR results improve
matching. Run `npm run validate:study:images` and `npm run test:study` before
publishing. Source PPTX hashes must match the registered source manifest.
