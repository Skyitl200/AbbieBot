# Question reports

After any /test answer, the private result card offers Report alongside Next
Question, Choose another class, or Retry coins. The student describes the error
in a private modal. Reports go to moderator channel **1549474402062704675**.

A report includes the issue, reporter, question ID, course/model, prompt, choices,
expected answer, explanation, source channel, public question link when available,
and the original question image if present. No wallet balance or score is sent.
Mentions cannot ping users or roles.

Only the quiz owner can open or submit its report. The answer records its displayed choice order and public question link;
the modal snapshots the question, so advancing or starting a new quiz cannot report the wrong card.
Forms last 30 minutes; duplicate submissions share one send, and Discord nonce
checks protect retries after uncertain sends. Delivery failures leave the issue
available when the student clicks Report again. Reports do not change grades,
coins, questions or image pointers.
